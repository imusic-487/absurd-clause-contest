An entry for the [make.fun competition "The Absurd Clause Contest"](https://make.fun/bounty/u-donrulezz-the-absurd-clause-contest-035cc0f1).

## The entry

> Should the user die while using the Service, their ghost agrees to remain on call for customer support for ninety (90) days.

The clause reads like deadpan legal boilerplate until the absurdity hits: a user who dies mid-session still owes the Service ninety days of customer-support duty — from beyond the grave.

## How it works

`main.py` (Python 3, standard library only) writes that one line to `/output/entry.txt`. No network, no environment, no randomness — the output is fixed and deterministic, 124 characters, one line, no trailing newline.
